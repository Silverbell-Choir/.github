## 소개

**SilverBell Choir**는 여러 소프트웨어 프로젝트를 하나의 일관된 구조 아래에서 개발하고 유지하기 위한 독립 개발 조직입니다.

실제 개발이 진행되는 저장소는 필요에 따라 **비공개(Private)** 로 운영하며, 사용자에게 필요한 지원·보안·기여 안내는 공개 저장소를 통해 제공합니다.

## 운영 방식

- 프로젝트별 개발은 각 저장소에서 독립적으로 진행합니다.
- 공개 지원 창구는 하나의 공용 지원 저장소로 통합합니다.
- 보안·기여·협업 지침은 조직 공용 기준을 사용합니다.
- 새로운 프로젝트가 추가되어도 같은 구조를 유지할 수 있도록 설계합니다.

## 지원

버그 제보, 기능 요청, 사용 문의, 문서 피드백은 공용 지원 저장소에서 받습니다.
