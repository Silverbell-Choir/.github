## About

**SilverBell Choir** is an independent software organization for building and maintaining products under a shared structure.

Some repositories remain **private during active development**. Public-facing support, contribution guidance, and community information stay in stable public locations so users always know where to start.

## How we work

- Product development stays focused and repository-specific
- Public support is centralized in one stable location
- Community and security guidance is shared across the organization
- The organization structure is designed to scale as new projects are added
