## SilverBell Choir

**SilverBell Choir**는 여러 소프트웨어 프로젝트를 일관된 구조 아래에서 개발하고 유지하기 위한 독립 개발 조직입니다.

> [!NOTE]
> 개발 저장소는 비공개로 운영될 수 있지만, 사용자에게 필요한 지원·보안·기여 안내는 공개된 공용 영역에서 확인할 수 있습니다.

## 운영 원칙

- **프로젝트 단위 분리** — 각 프로젝트의 개발 범위와 저장소를 독립적으로 유지합니다.
- **공개/비공개 경계 유지** — 공개 지원 영역과 실제 개발 영역을 분리합니다.
- **공용 지원 창구 유지** — 프로젝트가 늘어나도 사용자가 찾아야 할 지원 위치는 바뀌지 않게 합니다.
- **조직 공용 기준 사용** — 보안·기여·협업 문서는 조직 공용 기준을 우선 사용합니다.
