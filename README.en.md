# SilverBell Choir · Organization Defaults

[한국어](./README.md) · [English](./README.en.md)

This repository manages the public profile and shared community defaults for the **SilverBell Choir** organization.

## Included

- `profile/README.md` — public Organization profile
- `CONTRIBUTING.md` — shared contribution guidance
- `SECURITY.md` — security reporting guidance
- `SUPPORT.md` — support guidance
- `CODE_OF_CONDUCT.md` — shared conduct policy
- `.github/ISSUE_TEMPLATE/` — organization-wide issue guidance
- `PULL_REQUEST_TEMPLATE.md` — default pull request template

## Public support

For bug reports, feature requests, and general questions, use the shared support repository:

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## Operating principle

Working repositories may remain private during active development, while public support and community guidance stay available through this repository and the shared support hub.
