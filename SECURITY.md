# Security Policy

## Reporting a vulnerability

If you believe you found a security issue related to a project under **SilverBell Choir**, please **do not disclose full vulnerability details in a public issue**.

At this time, use the public support repository to request a private handoff:

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

### Recommended process

1. Open a new issue in the support repository.
2. Start the title with: `[SECURITY] Private disclosure requested`
3. Share only minimal high-level context in the public issue.
4. Wait for follow-up instructions before sharing sensitive technical details.

## Please include

- affected product or project name
- affected version or build, if known
- a short summary of the issue
- the potential impact
- whether the issue is actively exploitable, if known

## Scope

This policy applies to security reports for projects maintained under the SilverBell Choir organization.
