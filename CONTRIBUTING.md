# Contributing

Thank you for your interest in contributing to **SilverBell Choir** projects.

## Before you start

Because this organization can contain both public and private repositories, contribution paths may differ by project.

Please follow these general rules:

1. Read the repository README and any local contribution notes first.
2. Use the public support repository for general questions, bug reports, or feature requests unless a repository clearly asks for something else.
3. Keep pull requests focused and small when possible.
4. Do not publish sensitive information, credentials, or private implementation details.

## Public support and intake

Use the shared support repository for:

- bug reports
- feature requests
- documentation feedback
- general support questions

Support hub:

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## Pull requests

If you are opening a pull request to a repository in this organization:

- describe the goal clearly
- explain the change scope
- note any user-visible impact
- mention testing performed
- keep unrelated changes out of the same PR

## Conduct

Be respectful, clear, and concise in all discussions.
