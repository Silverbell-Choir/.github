# Support

For public support, bug reports, feature requests, and general questions, use the shared support repository:

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## Use the support repository for

- reporting bugs
- requesting features
- asking usage questions
- reporting documentation issues
- requesting help for current or future SilverBell Choir projects

## Security concerns

For security-related reports, read [`SECURITY.md`](./SECURITY.md) first and avoid posting sensitive technical details publicly.
