# Security Policy

[한국어](./SECURITY.md) · [English](./SECURITY.en.md)

## Reporting a vulnerability

If you believe you found a security issue in a SilverBell Choir project, **do not post sensitive vulnerability details in a public issue**.

For now, use the shared support repository to request a private handoff:

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

### Recommended process

1. Open a new issue in the shared support repository.
2. Start the title with `[SECURITY] Private disclosure requested`.
3. Share only minimal high-level context publicly.
4. Wait for private handoff instructions before sharing sensitive technical details.

## Helpful information

- affected product or project name
- affected version or build
- short summary of the issue
- expected impact or risk
- whether active exploitation is confirmed or suspected

## Scope

This policy applies to security reports for projects maintained under the SilverBell Choir organization.
