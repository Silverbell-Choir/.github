# SilverBell Choir · 조직 공용 설정

[한국어](./README.md) · [English](./README.en.md)

이 저장소는 **SilverBell Choir** Organization의 공개 프로필과 공용 커뮤니티 설정을 관리합니다.

## 포함 항목

- `profile/README.md` — Organization 공개 프로필
- `CONTRIBUTING.md` — 공용 기여 안내
- `SECURITY.md` — 보안 제보 안내
- `SUPPORT.md` — 지원 안내
- `CODE_OF_CONDUCT.md` — 공용 행동 규칙
- `.github/ISSUE_TEMPLATE/` — 조직 공용 이슈 안내
- `PULL_REQUEST_TEMPLATE.md` — 기본 Pull Request 템플릿

## 공용 지원

버그 제보, 기능 요청, 일반 문의는 아래 공용 지원 저장소를 이용합니다.

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## 운영 원칙

실제 작업 저장소는 개발 상황에 따라 비공개로 유지할 수 있으며, 공개 지원과 커뮤니티 안내는 이 저장소와 공용 지원 저장소를 통해 제공합니다.
