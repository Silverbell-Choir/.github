# SilverBell Choir · Organization Defaults

- `profile/README.md` — public Organization profile
- `CONTRIBUTING.md` — general contribution guidance
- `SECURITY.md` — security disclosure guidance
- `SUPPORT.md` — support guidance
- `.github/ISSUE_TEMPLATE/` — shared default issue configuration

For bug reports, feature requests, and general support, use:
