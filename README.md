# SilverBell Choir · 조직 공용 설정 / Organization Defaults

이 저장소는 **SilverBell Choir** 조직의 공개 프로필과 공용 커뮤니티 정책 파일을 관리합니다.

> This repository contains the public organization profile and shared community health files for **SilverBell Choir**.

## 포함 항목

- `profile/README.md` — GitHub Organization 공개 프로필
- `CONTRIBUTING.md` — 공용 기여 가이드
- `SECURITY.md` — 보안 제보 정책
- `SUPPORT.md` — 지원 안내
- `CODE_OF_CONDUCT.md` — 협업 행동 규칙
- `.github/ISSUE_TEMPLATE/` — 공용 이슈 설정
- `PULL_REQUEST_TEMPLATE.md` — 공용 Pull Request 템플릿

## 공용 지원

버그 제보, 기능 요청, 사용 문의는 아래 공개 지원 저장소에서 받습니다.

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## 저장소 공개 정책

실제 개발 저장소는 개발 단계와 프로젝트 성격에 따라 **Private** 상태로 운영할 수 있습니다. 공개 지원과 조직 공용 문서는 이 저장소 및 지원 저장소에 분리해 유지합니다.
