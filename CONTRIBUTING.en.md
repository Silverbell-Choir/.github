# Contributing

[한국어](./CONTRIBUTING.md) · [English](./CONTRIBUTING.en.md)

Thank you for your interest in SilverBell Choir projects.

## Before you start

Contribution paths and visibility may differ by project.

1. Read the repository README and any local contribution notes first.
2. Use the shared support repository for general questions, bug reports, and feature requests.
3. Keep pull requests focused on a single purpose when possible.
4. Do not publish passwords, tokens, private keys, private implementation details, or other sensitive information.

## Shared support hub

- [`Silverbell-Choir/silverbell-choir-support`](https://github.com/Silverbell-Choir/silverbell-choir-support)

## Pull requests

Please:

- describe the goal clearly
- explain the scope of the change
- note any user-visible impact
- mention testing or validation performed
- avoid mixing unrelated changes into the same PR

## Communication

Keep discussions clear and respectful.
